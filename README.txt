SELGAMIS® QUIZ – ΟΔΗΓΙΕΣ

Το index.html είναι αυτοτελές και περιλαμβάνει όλο το quiz.

ΣΗΜΑΝΤΙΚΟ:
Η προεπισκόπηση HTML σε εφαρμογές αρχείων ή μέσα στο ChatGPT μπορεί να
μπλοκάρει το JavaScript. Σε αυτή την περίπτωση εμφανίζεται η σελίδα, αλλά τα
κουμπιά δεν λειτουργούν.

Για αξιόπιστη χρήση από κινητό:
1. Ανεβάστε το index.html σε εταιρικό web server/intranet, GitHub Pages,
   Netlify ή αντίστοιχο static hosting.
2. Στείλτε στους συνεργάτες το κανονικό https:// link.
3. Το quiz δεν χρειάζεται database ή server-side κώδικα.

Πριν από εταιρική χρήση απαιτείται επιστημονικός έλεγχος της βάσης έναντι του
ισχύοντος SPC/SmPC και των εγκεκριμένων υλικών.
